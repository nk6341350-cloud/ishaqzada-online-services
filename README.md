# Ishaqzada Online Services

دا یو installable PWA prototype دی.

## مهم
دا نسخه د ازمایښت لپاره معلومات د browser LocalStorage کې ساتي.
د ریښتیني څو-موبایل/څو-شاګرد استعمال لپاره باید یو ګډ backend/database (لکه Supabase/Firebase) ورسره ونښلول شي.
همدا front-end جوړښت د backend سره د نښلولو لپاره چمتو دی.

## شاملې برخې
- پښتو، فارسی، English
- PWA install
- Student registration + admin approval
- Student PIN login
- Product registration/edit/delete
- Exact categories: شمپو، تیل، درمل، روغتیا، وزن، ویښتان، کریم، سیروم، نور
- Per-product student WhatsApp
- Customer order with automatic total
- Province, address, phone, GPS location
- Stock auto-decrement
- Admin dashboard
- Student unique shop link
- Footer address + complaint WhatsApp
